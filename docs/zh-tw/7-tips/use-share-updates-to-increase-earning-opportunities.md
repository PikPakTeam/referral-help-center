# 如何使用「分享更新」增加收益機會？

「分享更新」可以幫助您持續更新已分享的內容。開啟後，儲存並關注該分享的使用者可以查看您後續新增的新內容，無需您在每次更新後重新傳送分享。 持續提供用戶感興趣的內容，有助於吸引用戶再次查看您的分享，為您帶來更多獲得收益的機會。

**如何開啟「分享更新」？**

建立分享時：

1. 在 PikPak 中選擇需要分享的檔案或資料夾。
2. 點選「分享」，開啟分享設定頁面。
3. 頁面底部的「允許他人查看更新並關注此分享」預設為開啟。
4. 保持此選項開啟，選擇分享方式並完成分享。

對於已建立的分享，您可以進入「我的分享」，開啟對應的分享詳情，查看或管理該設定。

**用戶如何查看更新內容？**

當使用者開啟並儲存您的分享時，可以選擇關注該分享。

關注後，當您繼續向原分享添加新內容時，用戶可以透過 PikPak 中的「分享更新」、更新提醒或原分享頁面查看新增內容。

目前，「分享更新」功能僅在 PikPak 行動版 App 提供。您可以將分享連結或分享代碼傳送給用戶，並引導用戶下載安裝 PikPak App，以便查看後續更新內容。

**如何提高分享效果？**

使用「分享更新」時，建議注意以下幾點：

* 持續更新相同主題的內容：圍繞用戶感興趣的主題補充新內容，讓用戶更容易了解每次更新的價值。
* 優先更新原分享：如果新內容與原分享屬於同一主題，可以繼續更新原分享，不必重複建立多個相似分享。如果重新建立另一個分享，原分享的關注用戶不會自動關注新分享。
* 保持檔案結構清晰：使用容易辨識的資料夾和檔案名稱，方便使用者快速找到新增內容。
* 引導用戶儲存並關注：用戶儲存並關注該分享後，才能更方便地查看您後續發布的更新。
* 保持分享更新功能開啟：如果關閉「允許查看更新並關注」，用戶將無法繼續透過該功能查看後續更新。
* 避免頻繁修改分享密碼：修改分享密碼後，使用者可能需要重新輸入新密碼才能查看分享及其更新內容。如確需修改，請及時將新密碼告知使用者。
