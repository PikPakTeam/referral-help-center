# Siapa yang dapat mengaktifkan Distribusi Afiliasi?

Saat ini, Distribusi Afiliasi hanya tersedia untuk pengguna Referral Program Pro. Buka [Referral Options](https://mypikpak.com/referral/options) dan temukan bagian CLI & Developer Distribution. Untuk mengaktifkannya, setujui Ketentuan Afiliasi dan selesaikan verifikasi email.
