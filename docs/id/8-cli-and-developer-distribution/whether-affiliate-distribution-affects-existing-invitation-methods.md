# Apakah Distribusi Afiliasi memengaruhi metode undangan saya yang sudah ada?

Tidak. Kode Undangan Anda tetap sama dan masih dapat digunakan untuk undangan pribadi seperti biasa. Mengaktifkan Distribusi Afiliasi hanya membuat kode yang sama juga bisa dipakai untuk distribusi publik di PikPak CLI dan alat AI agent.
