# Mengapa kode saya tidak bisa digunakan untuk pendaftaran CLI?

Silakan periksa terlebih dahulu di "Referral Options" apakah Distribusi Afiliasi sudah diaktifkan. Jika statusnya Suspended, kode Anda tidak dapat digunakan sementara untuk pendaftaran baru melalui CLI atau alat AI agent, tetapi tetap dapat digunakan untuk undangan pribadi yang sudah ada. Jika Anda merasa status ini keliru, hubungi tim Dukungan PikPak.
