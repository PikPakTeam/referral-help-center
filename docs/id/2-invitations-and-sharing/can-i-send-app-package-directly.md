# Bisakah saya mengirim paket instalasi Aplikasi langsung ke pengguna baru?

Ya.

Selain membagikan tautan khusus Anda, Anda dapat menggunakan tautan tersebut untuk mengunduh paket instalasi dan mengirimkannya langsung ke pengguna baru. Setelah pengguna menginstal PikPak Aplikasi dan login berhasil, sistem akan menentukan apakah referral valid sesuai aturan program.
