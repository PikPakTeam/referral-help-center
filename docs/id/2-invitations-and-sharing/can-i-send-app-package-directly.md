# Bisakah saya mengirim paket instalasi aplikasi langsung ke pengguna baru?

Ya.

Selain membagikan tautan khusus Anda, Anda dapat menggunakan tautan tersebut untuk mengunduh paket instalasi dan mengirimkannya langsung ke pengguna baru. Setelah pengguna menginstal Aplikasi PikPak dan berhasil masuk, sistem akan menentukan apakah undangan valid sesuai aturan program.
