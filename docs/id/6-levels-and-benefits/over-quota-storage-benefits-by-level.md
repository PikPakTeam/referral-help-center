# Apa perbedaan manfaat penyimpanan melebihi kuota berdasarkan tingkatnya?

Tingkat yang berbeda memiliki aturan berbeda untuk mengelola penyimpanan yang melebihi milik AndaStorage Quota:

- **LV0:**Setelah penyimpanan Anda tetap melebihi kuota selama empat bulan berturut-turut, Anda memasuki masa tenggang dua bulan. Jika status kelebihan kuota tidak terselesaikan setelah total enam bulan, PikPak akan mulai menghapus file yang melebihi file AndaStorage Quota.
- **LV1:**Anda juga menerima masa tenggang tambahan selama empat bulanLV0aturan. Setelah penyimpanan Anda melebihi kuota selama empat bulan berturut-turut, Anda menerima total masa tenggang selama enam bulan. Ini berarti file melebihi file AndaStorage Quotatidak akan diproses hingga penyimpanan Anda melebihi kuota hingga sepuluh bulan berturut-turut.
- **LV2dan di atasnya:**Selagi kamu menjaganyaLV2atau tingkat yang lebih tinggi, masa tenggang kelebihan kuota terus diperpanjang, dan PikPak tidak akan menghapus file yang melebihi milik AndaStorage Quota.

Ketika level Anda berubah, tanggal mulai status kelebihan kuota Anda tidak diatur ulang. Sistem menilai kembali status masa tenggang Anda berdasarkan akumulasi durasi kelebihan kuota dan level Anda saat ini. Silakan lihat pemberitahuan email untuk mengetahui status Anda saat ini dan sisa waktu.
