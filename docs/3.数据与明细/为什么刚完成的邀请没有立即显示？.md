# 为什么刚完成的邀请没有立即显示？

邀请及收益数据需要一定时间完成统计和确认，因此不会实时显示。  
当日数据将在次日新加坡时间 14:00（UTC+8）前更新。  
若届时仍未显示，您可以发送邮件至 [support@mypikpak.com](mailto:support@mypikpak.com) 联系用户支持并附上您的 PikPak 账号。



---

## English

### Why doesn't a recent referral appear right away?

Referral and earnings data must be processed and verified, so it is not displayed in real time.

Data for the current day will be updated by 2:00 PM Singapore Time (UTC+8) the following day.

If the record is still not displayed after that time, email [support@mypikpak.com](mailto:support@mypikpak.com) and include your PikPak account information.
