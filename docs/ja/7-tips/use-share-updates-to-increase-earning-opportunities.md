# 「共有の更新」を活用して収益機会を増やすにはどうすればよいですか？

「共有の更新」を使うと、共有済みのコンテンツを継続的に更新できます。この機能を有効にすると、共有を保存してフォローしたユーザーは、更新のたびに共有し直さなくても、後から追加された新しいコンテンツを確認できます。 ユーザーが関心を持つコンテンツを継続して提供することで、ユーザーが再び共有を閲覧する機会が増え、収益機会の拡大につながります。

**「共有の更新」を有効にするにはどうすればよいですか？**

共有を作成する場合：

1. PikPakで共有するファイルまたはフォルダーを選択します。
2. 「共有」をタップして、共有設定ページを開きます。
3. ページ下部の「他のユーザーに更新の表示とこの共有のフォローを許可する」は、初期設定で有効になっています。
4. この設定を有効のままにして共有方法を選び、共有を完了します。

作成済みの共有については、「マイ共有」から該当する共有の詳細を開き、設定を確認または管理できます。

**ユーザーは更新内容をどのように確認できますか？**

ユーザーは共有を開いて保存する際に、その共有をフォローできます。

フォロー後、元の共有に新しいコンテンツを追加すると、ユーザーはPikPakの「共有の更新」、更新通知、または元の共有ページから新しいコンテンツを確認できます。

現在、「共有の更新」機能はPikPakモバイルアプリでのみ利用できます。共有リンクまたは共有コードをユーザーに送り、PikPakアプリをダウンロードしてインストールするよう案内すると、今後の更新を確認できるようになります。

**共有の効果を高めるにはどうすればよいですか？**

「共有の更新」を利用する場合は、次の点をおすすめします。

* 同じテーマのコンテンツを継続的に更新する：ユーザーが関心を持つテーマに沿って新しいコンテンツを追加すると、各更新の価値が伝わりやすくなります。
* まず元の共有を更新する：新しいコンテンツと元の共有が同じテーマの場合は、似た共有を何度も作成せず、元の共有を更新できます。別の共有を新しく作成しても、元の共有をフォローしているユーザーが新しい共有を自動的にフォローすることはありません。
* ファイル構成を分かりやすく保つ：分かりやすいフォルダー名とファイル名を使用し、ユーザーが新しいコンテンツをすぐに見つけられるようにします。
* 保存とフォローを案内する：ユーザーが共有を保存してフォローすると、その後の更新を確認しやすくなります。
* 「共有の更新」を有効にしておく：「更新の表示とフォローを許可する」を無効にすると、ユーザーはこの機能を通じて以降の更新を確認できなくなります。
* 共有パスワードを頻繁に変更しない：共有パスワードを変更すると、ユーザーが共有と更新済みコンテンツを表示する際に、新しいパスワードの再入力が必要になる場合があります。変更が必要な場合は、新しいパスワードを速やかにユーザーへお知らせください。
