# 新しいユーザーを紹介するにはどうすればよいですか？

ファイルの共有リンク、アプリのインストールリンク、Premium購入リンク、公式サイトのリンク、Torrentプロモーションページのリンク、アプリの紹介コードなどを共有して、新しいユーザーを紹介できます。 新しいユーザーが該当する方法で登録、ファイルの保存、アプリのインストールなどを完了すると、システムが紹介の有効性を判定します。 PikPak CLI または AI agent ツールで招待コードを使用する場合は、[CLI と開発者向け配布](../8-cli-and-developer-distribution/)をご確認ください。
