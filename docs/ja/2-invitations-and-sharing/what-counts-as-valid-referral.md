# 有効な紹介とは何ですか？

有効な紹介の判定ルールは次のとおりです。 ファイル共有で紹介する場合、新しいユーザーは登録後12時間以内に、共有されたファイルを保存する必要があります。登録から12時間を超えた場合、有効な新規ユーザーとはみなされません。 専用リンクで紹介する場合、新しいユーザーはPikPakアプリをダウンロードし、ログインを完了する必要があります。紹介されたユーザーがiOS端末を使用している場合は、App Storeからアプリをダウンロードした後に紹介コードを入力すると、有効な紹介とみなされます。 紹介コードで紹介する場合、新しいユーザーは登録後12時間以内に紹介コードを入力する必要があります。また、端末、アカウント、ネットワークなどのリスク情報に基づいて総合的に判定されます。

同一端末、同一決済アカウント、異常なIPアドレス帯、または同一出金アカウントに関連付けられた紹介は、有効な紹介として1回のみカウントされます。PikPakは、システムのリスク管理およびセキュリティ監査ログに基づき、水増し、虚偽登録、大量登録、アカウントの不正利用、自己購入、自己紹介などの不正行為を独自に判定・除外する最終的な権限を有します。
