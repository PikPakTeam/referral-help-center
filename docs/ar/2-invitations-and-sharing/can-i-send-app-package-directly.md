# هل يمكنني إرسال حزمة تثبيت التطبيق مباشرة إلى مستخدم جديد؟

نعم.

بالإضافة إلى مشاركة الرابط المخصص لك، يمكنك استخدام الرابط لتنزيل حزمة التثبيت وإرسالها مباشرة إلى مستخدم جديد. بعد أن يقوم المستخدم بتثبيت PikPak بعد التطبيق وتسجيل الدخول بنجاح، سيحدد النظام ما إذا كانت الإحالة صالحة وفقًا لقواعد البرنامج.
