# ما الذي يُعد شراء Premium ناجحًا؟

يُعد المستخدم الجديد قد اشترى Premium بنجاح إذا فعّل Premium خلال سنة واحدة (365 يومًا) من التسجيل عبر اشتراك Premium الرسمي، أو الشراء داخل التطبيق، أو Premium Code، أو Experience Premium Code. أما Premium الذي يتم الحصول عليه عبر Redeem Code مجاني، أو وقت Premium مهدى، أو أي طريقة مجانية أخرى، فلا يُعد شراء Premium ولن يولّد عمولة Premium.

وتخضع النتيجة النهائية لحالة الطلب في النظام وفحوصات الصلاحية.
