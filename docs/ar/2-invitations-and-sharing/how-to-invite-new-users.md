# كيف يمكنني دعوة مستخدمين جدد؟

يمكنك دعوة المستخدمين عبر مشاركة روابط الملفات، أو روابط تثبيت تطبيق PikPak، أو روابط شراء Premium، أو روابط الموقع الرسمي، أو روابط صفحة ترويج Torrent، أو رمز دعوة التطبيق الخاص بك.

يجب على المستخدمين الجدد إكمال الإجراءات المطلوبة وفق طريقة الدعوة، مثل التسجيل أو حفظ الملفات أو تثبيت تطبيق PikPak. بعد ذلك يحدد النظام ما إذا كانت الإحالة صالحة.
لاستخدام رمز الدعوة الخاص بك في PikPak CLI أو أدوات AI agent، راجع [CLI وتوزيع المطورين](../8-cli-and-developer-distribution/README.md).
