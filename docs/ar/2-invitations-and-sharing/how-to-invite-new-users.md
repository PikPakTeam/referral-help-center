# كيف يمكنني دعوة مستخدمين جدد؟

يمكنك دعوة المستخدمين من خلال مشاركة روابط الملفات،PikPak روابط تثبيت التطبيق، أو روابط الشراء المميزة، أو روابط موقع الويب الرسمي، أو روابط صفحة ترويج Torrent، أو تطبيقكInvitation Code.

يجب على المستخدمين الجدد إكمال الإجراءات المطلوبة لطريقة الدعوة ذات الصلة، مثل التسجيل أو حفظ الملفات أو تثبيت الملف PikPak برنامج. سيحدد النظام بعد ذلك ما إذا كانت الإحالة صالحة أم لا.
