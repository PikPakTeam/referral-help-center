# لماذا لا يمكن استخدام رمزي للتسجيل عبر CLI؟

يرجى أولاً التأكد من صفحة "Referral Options" مما إذا كان التوزيع بالعمولة مفعّلًا. إذا كانت الحالة Suspended، فلن يمكن استخدام رمزك مؤقتًا في عمليات التسجيل الجديدة عبر CLI أو أدوات AI agent، لكنه يظل صالحًا للدعوات الخاصة الحالية. إذا كنت تعتقد أن الحالة غير صحيحة، فتواصل مع فريق دعم PikPak.
