# متى يجب أن أستخدم أ رمز المشاركة?

إذا كان من الصعب إرسال رابط مشاركة كامل، أو إذا لم يتمكن النظام الأساسي من عرض الروابط أو فتحها مباشرة، فيمكنك إنشاء رابط أقصر رمز المشاركة للمحتوى الخاص بك وأرسل الرمز بدلاً من ذلك.

يمكنك أن تطلب من المستخدمين تنزيل الملف وفتحه PikPak التطبيق، ثم أدخل الخاص بك رمز المشاركة من خلال البحث أو إضافة رابط أو رمز المشاركة الدخول على الصفحة الرئيسية لعرض أو حفظ المحتوى المشترك الخاص بك.
