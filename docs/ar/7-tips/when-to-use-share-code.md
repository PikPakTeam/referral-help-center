# متى ينبغي استخدام رمز المشاركة؟

إذا كان رابط المشاركة الكامل صعب الإرسال، أو كان أحد المنصات لا يستطيع عرض الروابط أو فتحها مباشرة، يمكنك إنشاء رمز مشاركة أقصر وإرسال الرمز بدلًا من الرابط.

يمكنك أن تطلب من المستخدمين تنزيل تطبيق PikPak وفتحه، ثم إدخال رمز المشاركة عبر البحث أو إضافة رابط أو مدخل رمز المشاركة في الصفحة الرئيسية لعرض المحتوى المشترك أو حفظه.
