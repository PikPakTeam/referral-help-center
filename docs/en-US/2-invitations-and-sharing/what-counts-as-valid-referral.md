# What counts as a valid referral?

A referral is considered valid when the following requirements are met:

* For referrals through file sharing, the new user must save the file you shared within 12 hours of signing up. Users who save the file more than 12 hours after signing up will not be considered valid new users.
* For referrals through a dedicated link, the new user must download the PikPak App and log in successfully. On iOS, the invited user must also enter the Invitation Code after downloading the App from the App Store.
* For referrals through an Invitation Code, the new user must enter the code within 12 hours of signing up. The system may also consider device, account, network, and other risk-related information.

Referrals associated with the same device or payment account, an abnormal IP range, or the same withdrawal account linked to the inviter will only be counted once. Based on its risk control systems and security audit logs, PikPak has sole discretion to identify and filter abnormal or fraudulent activity, including artificial traffic generation, fake or bulk registrations, fraudulent payments, and self-referrals.
