# How can I invite new users?

You can invite users by sharing file links, PikPak App installation links, Premium purchase links, official website links, Torrent promotion page links, or your App Invitation Code.

New users must complete the required actions for the relevant invitation method, such as signing up, saving files, or installing the PikPak App. The system will then determine whether the referral is valid.
To use your Invitation Code in PikPak CLI or AI agent tools, see [CLI & Developer Distribution](../8-cli-and-developer-distribution/README.md).
