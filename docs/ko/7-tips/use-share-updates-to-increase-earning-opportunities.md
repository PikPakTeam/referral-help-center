# ‘공유 업데이트’를 활용해 수익 기회를 늘리려면 어떻게 해야 하나요?

‘공유 업데이트’를 사용하면 이미 공유한 콘텐츠를 계속 업데이트할 수 있습니다. 이 기능을 켜면 공유를 저장하고 팔로우한 사용자는 업데이트할 때마다 공유를 다시 보내지 않아도 나중에 추가된 새 콘텐츠를 볼 수 있습니다.
사용자가 관심을 가질 만한 콘텐츠를 꾸준히 제공하면 사용자가 공유를 다시 확인하도록 유도하여 수익 기회를 늘릴 수 있습니다.

**‘공유 업데이트’를 켜려면 어떻게 해야 하나요?**

공유를 만들 때:

1. PikPak에서 공유할 파일이나 폴더를 선택합니다.
2. ‘공유’를 눌러 공유 설정 페이지를 엽니다.
3. 페이지 하단의 ‘다른 사용자가 업데이트를 보고 이 공유를 팔로우하도록 허용’은 기본적으로 켜져 있습니다.
4. 이 옵션을 켠 상태로 공유 방법을 선택하고 공유를 완료합니다.

이미 만든 공유는 ‘내 공유’에서 해당 공유의 상세 페이지를 열어 설정을 확인하거나 관리할 수 있습니다.

**사용자는 업데이트 내용을 어떻게 확인하나요?**

사용자는 공유를 열어 저장할 때 해당 공유를 팔로우할 수 있습니다.

팔로우한 뒤 원래 공유에 새 콘텐츠를 계속 추가하면, 사용자는 PikPak의 ‘공유 업데이트’, 업데이트 알림 또는 원래 공유 페이지에서 새 콘텐츠를 확인할 수 있습니다.

현재 ‘공유 업데이트’ 기능은 PikPak 모바일 앱에서만 사용할 수 있습니다. 사용자에게 공유 링크나 공유 코드를 보내고 PikPak 앱을 다운로드하여 설치하도록 안내하면 이후 업데이트를 확인할 수 있습니다.

**공유 효과를 높이려면 어떻게 해야 하나요?**

‘공유 업데이트’를 사용할 때는 다음 사항을 권장합니다.

- 같은 주제의 콘텐츠를 꾸준히 업데이트하기: 사용자가 관심을 가질 만한 주제를 중심으로 새 콘텐츠를 추가하면 각 업데이트의 가치를 쉽게 이해할 수 있습니다.
- 원래 공유를 우선 업데이트하기: 새 콘텐츠가 원래 공유와 같은 주제라면 비슷한 공유를 반복해서 만들지 않고 원래 공유를 계속 업데이트할 수 있습니다. 별도의 공유를 새로 만들면 원래 공유를 팔로우한 사용자가 새 공유를 자동으로 팔로우하지 않습니다.
- 파일 구조를 명확하게 유지하기: 알아보기 쉬운 폴더명과 파일명을 사용하여 사용자가 새 콘텐츠를 빠르게 찾도록 합니다.
- 저장 및 팔로우 안내하기: 사용자가 공유를 저장하고 팔로우해야 이후 업데이트를 더 쉽게 확인할 수 있습니다.
- ‘공유 업데이트’를 계속 켜 두기: ‘업데이트 보기 및 팔로우 허용’을 끄면 사용자는 이 기능을 통해 이후 업데이트를 볼 수 없습니다.
- 공유 비밀번호를 자주 변경하지 않기: 공유 비밀번호를 변경하면 사용자가 공유와 업데이트된 콘텐츠를 보기 위해 새 비밀번호를 다시 입력해야 할 수 있습니다. 반드시 변경해야 하는 경우 새 비밀번호를 사용자에게 즉시 알려 주세요.
