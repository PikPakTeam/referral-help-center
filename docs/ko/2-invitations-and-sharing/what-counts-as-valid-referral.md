# 유효한 추천이란 무엇인가요?

유효한 추천의 판정 규칙은 다음과 같습니다.
파일 공유로 추천하는 경우, 신규 사용자는 가입 후 12시간 이내에 공유된 파일을 저장해야 합니다. 가입 후 12시간이 지나면 유효한 신규 사용자로 인정되지 않습니다.
전용 링크로 추천하는 경우, 신규 사용자는 PikPak 앱을 다운로드하고 로그인해야 합니다. 추천받은 사용자가 iOS 기기를 사용하는 경우 App Store에서 앱을 다운로드한 후 추천 코드를 입력해야 유효한 추천으로 인정됩니다.
추천 코드로 추천하는 경우, 신규 사용자는 가입 후 12시간 이내에 추천 코드를 입력해야 합니다. 또한 기기, 계정, 네트워크 등의 위험 정보를 바탕으로 종합적으로 판정합니다.

동일한 기기, 동일한 결제 계정, 비정상적인 IP 대역 또는 동일한 출금 계정과 연결된 추천은 유효한 추천으로 한 번만 집계됩니다. PikPak은 시스템 위험 관리 및 보안 감사 로그를 바탕으로 실적 부풀리기, 허위 가입, 대량 가입, 계정 도용, 자기 구매, 자기 추천 등의 비정상적 부정행위를 독립적으로 판정하고 제외할 최종 권한을 보유합니다.
