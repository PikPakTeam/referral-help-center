## 需求背景

将各语言文档导航中的 `SUMMARY.md` 标题与对应 Markdown 文档正文标题保持一致，并以文档内的一级标题（`# `）作为唯一来源。

## 涉及文件

- `docs/SUMMARY.md`
- `docs/en-US/SUMMARY.md`
- `docs/id/SUMMARY.md`
- `docs/ms/SUMMARY.md`

## 逻辑变动

- 以 `SUMMARY.md` 中每个链接指向的 Markdown 文档一级标题作为目标标题。
- 当 `SUMMARY.md` 标题与文档一级标题不一致时，使用文档一级标题覆盖原有导航标题。
- 根级 `docs/SUMMARY.md` 中各语言入口标题也统一改为各语言 `README.md` 的一级标题。

## 删除了哪些旧逻辑

- 未删除正文内容。
- 未删除导航节点。
- 删除了 `SUMMARY.md` 中与文档正文标题不一致的旧标题文本。

## 为什么删除这些旧逻辑

- 原有 `SUMMARY.md` 标题与正文标题存在大小写不一致、语言入口名称不一致、个别标题被截断等问题。
- 保留两套标题来源会导致导航与正文表达不一致，增加后续维护成本。
- 将正文一级标题作为单一事实来源后，后续只需维护文档内容本身即可。

## 新方案的收益与影响

- 导航标题与正文标题完全对齐，减少阅读落差。
- 后续批量校验可以直接基于文档一级标题进行。
- 本次同步会保留正文中已有的异常标题形式；例如源文档标题如果本身被截断，`SUMMARY.md` 会同步呈现相同结果。
