# Bagaimanakah cara saya meminta pengeluaran?

Sebaik sahaja anda Pendapatan Boleh Dikeluarkan mencapai jumlah pengeluaran minimum, anda boleh memilih Kaedah Pembayaran yang tersedia pada Referral Program Pro halaman dan serahkan permintaan pengeluaran. Pastikan butiran pembayaran anda betul sebelum menyerahkan.
