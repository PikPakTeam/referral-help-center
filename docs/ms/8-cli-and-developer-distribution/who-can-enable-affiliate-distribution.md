# Siapakah yang boleh mengaktifkan Pengedaran Afiliasi?

Pada masa ini, Pengedaran Afiliasi hanya tersedia untuk pengguna Referral Program Pro. Pergi ke [Pilihan Rujukan](https://mypikpak.com/referral/options) dan cari bahagian CLI & Developer Distribution. Untuk mengaktifkannya, anda perlu bersetuju dengan Terma Afiliasi dan melengkapkan pengesahan e-mel.
