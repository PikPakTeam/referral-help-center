# Bagaimanakah cara menggunakan kod saya dalam PikPak CLI?

Tambahkan pilihan `--affiliate` pada arahan pendaftaran, contohnya:

```bash
pikpak auth register --affiliate YOUR_CODE
```

Alat juga boleh menghantar kod melalui pemboleh ubah persekitaran `PIKPAK_AFFILIATE`. Jika kedua-duanya ditetapkan, pilihan `--affiliate` dalam arahan pendaftaran akan diutamakan.
