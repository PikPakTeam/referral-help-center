# Mengapakah kod saya tidak boleh digunakan untuk pendaftaran CLI?

Sila semak dahulu di "Referral Options" sama ada Pengedaran Afiliasi telah diaktifkan. Jika statusnya Suspended, kod anda buat sementara waktu tidak boleh digunakan untuk pendaftaran baharu melalui CLI atau alat AI agent, tetapi masih boleh digunakan untuk jemputan peribadi sedia ada. Jika anda percaya status ini tidak tepat, sila hubungi pasukan Sokongan PikPak.
