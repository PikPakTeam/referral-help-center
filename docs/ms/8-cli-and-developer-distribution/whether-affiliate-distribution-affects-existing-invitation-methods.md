# Adakah Pengedaran Afiliasi menjejaskan kaedah jemputan sedia ada saya?

Tidak. Kod Jemputan anda kekal sama dan masih boleh digunakan untuk jemputan peribadi seperti biasa. Mengaktifkan Pengedaran Afiliasi hanya membolehkan kod yang sama turut digunakan untuk pengedaran awam dalam PikPak CLI dan alat AI agent.
