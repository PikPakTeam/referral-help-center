# 如何使用「分享更新」增加收益机会？

「分享更新」可以帮助您持续更新已经分享的内容。开启后，保存并关注该分享的用户可以查看您后续添加的新内容，无需您在每次更新后重新发送分享。  
持续提供用户感兴趣的内容，有助于吸引用户再次查看您的分享，为您带来更多获得收益的机会。



**如何开启「分享更新」？**

创建分享时：

1. 在 PikPak 中选择需要分享的文件或文件夹。
2. 点击「分享」，打开分享设置页面。
3. 页面底部的「允许他人查看更新并关注此分享」默认处于开启状态。
4. 保持该选项开启，选择分享方式并完成分享。

对于已经创建的分享，您可以进入「我的分享」，打开相应的分享详情，查看或管理该设置。



**用户如何查看更新内容？**

用户打开并保存您的分享时，可以选择关注该分享。

关注后，当您继续向原分享添加新内容时，用户可以通过 PikPak 中的「分享更新」、更新提醒或原分享页面查看新增内容。

目前，「分享更新」功能仅在 PikPak 移动端 App 提供。您可以将分享链接或分享代码发送给用户，并引导用户下载安装 PikPak App，以便查看后续更新内容。



**如何提高分享效果？**

使用「分享更新」时，建议注意以下几点：

- 持续更新同一主题的内容：围绕用户感兴趣的主题补充新内容，让用户更容易了解每次更新的价值。
- 优先更新原分享：如果新内容与原分享属于同一主题，可以继续更新原分享，不必重复创建多个相似分享。如果重新创建另一个分享，原分享的关注用户不会自动关注新分享。
- 保持文件结构清晰：使用容易识别的文件夹和文件名称，方便用户快速找到新增内容。
- 引导用户保存并关注：用户保存并关注该分享后，才能更方便地查看您后续发布的更新。
- 保持分享更新功能开启：如果关闭「允许查看更新并关注」，用户将无法继续通过该功能查看后续更新。
- 避免频繁修改分享密码：修改分享密码后，用户可能需要重新输入新密码才能查看分享及其更新内容。如确需修改，请及时将新密码告知用户。

## English

### How can I use Share Updates to create more earning opportunities?

Share Updates lets you keep previously shared content up to date. Once enabled, users who save and follow the share can view content you add later, so you do not need to resend the share every time you update it.

Continuing to share content that users find useful can encourage them to return to your share and create more opportunities for you to earn.

**How do I enable Share Updates?**

When creating a share:

1. Select the files or folders you want to share in PikPak.
2. Tap Share to open the Share panel.
3. Allow viewing of updates and following is enabled by default at the bottom of the panel.
4. Keep it enabled, choose a sharing method, and complete the share.

For an existing share, go to My Sharing and open the share details to view or manage this setting.

**How do users view new content?**

When users open and save your share, they can choose to follow it.

After following the share, users can view content you add later through Share Updates, update notifications, or the original share page in PikPak.

Share Updates is currently available only in the PikPak Mobile App. You can send users a share link or Share Code and ask them to install the PikPak App to view future updates.

**How can I improve my sharing results?**

When using Share Updates, consider the following tips:

- **Keep updates focused on the same topic:** Add content related to topics your users care about so they can quickly understand the value of each update.
- **Update the original share whenever possible:** If new content is related to the same topic, continue updating the original share instead of creating multiple similar shares. Users who follow the original share will not automatically follow a newly created share.
- **Keep your file structure clear:** Use recognizable folder and file names so users can quickly find new content.
- **Encourage users to save and follow the share:** Users who save and follow the share can more easily view content you add later.
- **Keep Share Updates enabled:** If you turn off Allow viewing of updates and following, users will no longer be able to use this feature to view future updates.
- **Avoid changing the share password frequently:** After you change the share password, users may need to enter the new password before they can view the share and its updates. If you need to change it, make sure to send users the new password.
