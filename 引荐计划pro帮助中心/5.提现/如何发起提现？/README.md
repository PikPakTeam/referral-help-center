# 如何发起提现？

当可提现余额达到最低提现金额后，您可以在引荐计划 Pro 页面选择支持的收款方式并提交提现申请。请确认收款信息准确无误。

---

## English

### How do I request a withdrawal?

Once your Withdrawable Earnings reach the minimum withdrawal amount, you can select an available Payment Method on the Referral Program Pro page and submit a withdrawal request. Make sure your payment details are correct before submitting.
