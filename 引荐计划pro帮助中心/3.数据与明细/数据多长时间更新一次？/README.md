# 数据多长时间更新一次？

统计数据每天更新一次。由于数据计算需要一定时间，当日的邀请及收益数据将在次日新加坡时间 14:00（UTC+8）前显示。



---

## English

### How often is the data updated?

Statistics are updated once a day. Because data processing takes time, referral and earnings data for the current day will be available by 2:00 PM Singapore Time (UTC+8) the following day.
