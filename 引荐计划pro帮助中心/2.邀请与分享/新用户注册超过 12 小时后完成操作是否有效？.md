# 新用户注册超过 12 小时后完成操作是否有效？

通过文件分享保存文件或填写邀请码时，新用户需要在注册后 12 小时内完成对应操作。

超过该时间完成的操作不会被认定为有效邀请。

---

## English

### Is an action still valid if the new user completes it more than 12 hours after signing up?

For file-sharing referrals and Invitation Code referrals, the new user must save the shared file or enter the Invitation Code within 12 hours of signing up.

Actions completed after this period will not be considered valid referrals.
