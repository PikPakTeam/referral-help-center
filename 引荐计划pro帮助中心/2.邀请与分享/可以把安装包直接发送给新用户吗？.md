# 可以把安装包直接发送给新用户吗？

可以。  
除直接分享专属链接外，您也可以通过专属链接下载安装包，再将安装包发送给新用户。新用户安装并成功登录后，系统会根据规则判断该邀请是否有效。



---

## English

### Can I send the App installation package directly to a new user?

Yes.

In addition to sharing your dedicated link, you can use the link to download the installation package and send it directly to a new user. After the user installs the PikPak App and logs in successfully, the system will determine whether the referral is valid according to the program rules.
