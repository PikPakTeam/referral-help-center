# 同一个用户可以被重复计入吗？

不可以。同一用户通常只会被计算为一名邀请人的有效新用户一次。

系统可能根据设备、账号及其他关联信息识别重复记录。



---

## English

### Can the same user be counted more than once?

No. A user can generally be counted as a valid new user for only one inviter.

The system may use device, account, and other associated information to identify duplicate records.
